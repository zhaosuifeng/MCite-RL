# Data examples

Small real Wiki-VISA format examples: 2 train rows, 1 validation row and 2 test rows, plus their reference page images. JSONL mirrors the parquet files for inspection. All first-user prompts use prompts/wiki_visa_sft_gemini.txt. No retrieval index is included. These are format and smoke-test examples, not a training or evaluation benchmark. Keep the original Wiki-VISA dataset attribution and obtain full data separately.

Source dataset: MrLight/wiki-visa. Images are original reference pages, not model outputs. Page IDs are retained for mapping. Images live under data/examples/images.
